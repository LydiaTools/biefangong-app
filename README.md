# Scope Check

**客户一句“顺便改下”，可能就是一轮免费返工。**

「别返工」是一款独立的 macOS 商业产品，面向在微信、飞书等聊天工具里接需求的独立开发者、设计师、代运营、视频制作者、顾问和小型外包团队。

它不卖一套提问方法，而是持续保存每个项目的当前约定。客户再发新需求时，产品会识别：

- 新增了哪些工作；
- 原约定哪里变了；
- 哪些内容明确取消；
- 哪些要求还不能开工；
- 应该怎样给客户发一条边界清楚的确认回复。

## 使用闭环

1. 输入项目名，保存当前双方约定。
2. 粘贴客户新发的需求或修改。
3. 点“识别本次变更”，查看结构化差异和确认草稿。
4. 草稿只放回聊天输入框，不自动发送。
5. 用户认可比对结果后，才更新本机项目约定，并保留上一版。

## 与「说人话」的边界

这是两款不同产品：

- 应用名：「别返工」；
- Bundle ID：`com.lydiahub.biefangong`；
- URL Scheme：`lydia-scope`；
- 全局快捷键：`Control + Option + D`；
- 本机项目数据、开发用 Key 和应用设置都与「说人话」隔离；
- 两个 App 可以同时安装。

## 数据边界

- 项目名、当前约定和最近 30 个版本保存在本机，最多 20 个项目。
- 只有用户主动点击识别时，当前约定和新消息才会发给已连接的 AI。
- 产品不后台扫描聊天，不自动发送，不在用户确认前更新项目约定。
- 无 Key 时会使用本机规则核对常见的移动端、导出、登录、支付、权限、报表、搜索和提醒类变更，结果会随粘贴内容真实变化。
- 遇到更复杂、更口语化或依赖上下文的消息，可在开发设置中连接智谱 AI；任何核对结果都需要用户发送前确认。
- 安装包内附带「独立开发者夜航」桌面背景，用真实工作桌面承接产品氛围，不把工具包装成玩具。

## 本地构建

```bash
./scripts/test.sh
./scripts/build.sh
open build/v0.1.0/别返工.app
```

当前目标是 Apple Silicon、macOS 13 及以上。本地候选版使用 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证。
